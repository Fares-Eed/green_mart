> 🚧 **Status:** Under Development (Phase 1: UI & Auth)  (Phase 2:Main App Screen (Shop))  (Phase 3: Product Details, Search, and Beverages Screens)

## 🗺️ Roadmap & Features

**✅ Completed (Current Version):**
- **Clean UI Architecture:** Responsive design implementation.
- **Onboarding Flow:** Splash & Welcome screens.
- **Authentication UI:** Login & Registration screens.
- **Forget Password UI:** Number & Verification screens.
- **Main App Screens:** shope screen & Product Details Screen..
  
  
**🔜 Coming Soon:**
- Cart & Checkout Implementation.
- Backend Integration (Firebase/API).
- State Management Logic.

## 🛠️ Tech Stack

- **Framework:** Flutter (Dart)
- **State Management:** [Provider / Bloc / Riverpod] - **Architecture:** MVVM / Clean Architecture

## 🚀 Run Locally

If you want to test the UI on your machine:

1. **Clone the repository**
   ```bash
   git clone [https://github.com/Fares-Eed/green_mart.git](https://github.com/Fares-Eed/green_mart.git)
   cd green_mart
   Install dependencies

2. **Install dependencies**
   ```bash
   flutter pub get
3. **Run the app**
   ```bash
   flutter run
